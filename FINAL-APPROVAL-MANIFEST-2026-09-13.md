## Final product decisions included

- Wamadat is permanently a Single-Academy product.
- Launch V1 includes Tap / Tabby / Tamara + Bank Transfer integration capability.
- Launch V1 includes GTM / GA4 / Meta Pixel / TikTok Pixel / Snapchat Pixel and current commerce analytics.
- Program Interest / Waitlist is part of Launch V1 delivered scope.
- Mobile App is an early post-V1 priority.
- New Mobile App technology is Flutter for Android/iOS.
- React Native/Expo legacy mobile code is retired and will not be reused.
- Multi-academy product expansion is not part of the roadmap.

## 2. Alert delivery

### Current channels (verified end-to-end this turn)

The `Wamadat-Failed-Jobs-Check` Task Scheduler entry runs `check-failed-jobs.ps1` every 15 minutes. On `failed_jobs > 0` it fires alerts via three layered channels:

| # | Channel | Visible if operator is… | Persistence |
|---|---|---|---|
| 1 | **Windows toast notification** | logged in + at the machine | none (transient) |
| 2 | **`docs/operations/alerts-log.txt`** append | running daily summary | append-only file on local disk |
| 3 | **`OneDrive\Wamadat-Backups\ALERTS\alert-YYYYMMDD.txt`** | accessible from any device synced to OneDrive | file in OneDrive — survives local-machine failure |

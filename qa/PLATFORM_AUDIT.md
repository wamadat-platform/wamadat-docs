> والحالة المُتحقَّقة فعليًا حتى اللحظة. لا يحوي أي نتيجة غير مُثبَتة بدليل.

## ملخّص تنفيذي (حتى الآن)
منصّة LMS عربية متعدّدة المستأجرين، ناضجة معماريًا (27 موديول DDD، 129 جدولًا/مستأجر،
50 مورد Filament عبر 3 لوحات). حالة الإنتاج: حيّة (`api.wmt.sa` = `healthy`)، CI أخضر
5/5. هذا التدقيق يركّز على لوحة `/admin`، العزل بين المستأجرين، المسار المالي،
والمصادقة — مع بناء منشئ صفحات هبوط موحّد.

## المنهج (تصحيح أداة مهم)
اختبار لوحة Filament **لا يتم عبر المتصفّح** (المتصفّح المدمج يتعثّر على صفحات
Livewire الثقيلة، وهو غير موثوق لمصفوفة 50 موردًا × عشرات الحالات). الطريقة المهنية
المعتمدة هنا:
- **Filament Livewire harness** (`livewire(ListX::class)->assertOk()`, `fillForm`,
  `callTableAction`, `assertTableColumnExists`) — دليل حقيقي لكل مورد.
- **تمثيل الأدوار** (`actingAs`) لاختبار الصلاحيات (12 دورًا) والعزل.
- **Pest feature tests** لمسارات API (مصادقة، دفع، webhooks) — موجودة أصلًا وتُوسَّع.
- **Playwright** لرحلات المستخدم النهائية فقط (المكان الصحيح للمتصفّح).
- فحص قاعدة البيانات مباشرة (`psql`) للتحقّق من الأثر الفعلي، لا استجابة HTTP وحدها.

## المُتحقَّق فعليًا (بدليل)
- **السويت الخلفي الكامل**: يعمل الآن — النتيجة في `TEST_REPORT.md` عند الاكتمال.
- **CI**: 5/5 أخضر (آخر ركض على `main`).
- **الإنتاج حيّ**: `GET /api/v1/health → healthy` (يعني نجاح كل الفحوص: scheduler+queue+db).
- **مظروف الأخطاء المُعالَجة**: `POST /auth/login` بكلمة خاطئة → `401 {"error":{"code":"INVALID_CREDENTIALS"}}` (مُتحقَّق على الإنتاج).
- **جرد /admin**: 50 موردًا، 3 لوحات، 12 مجموعة تنقّل (ADMIN_PAGE_INVENTORY.md).

## المخاطر المرصودة (للتحقّق في الدفعات القادمة)
- **P1 تسريب حسّاس محتمل**: `UserResource` (هوية مشفّرة) و`BankTransferResource`
  (IBAN) — يجب التأكّد ألا تظهر في الأعمدة/الفلاتر/التصدير. **بند اختبار أمني.**
- **P2 صلاحيات الموارد التقنية**: EmailOutbox, FailedJob, PaymentWebhook, TenantAuditLog,
  MediaAsset, UserConsent — تأكيد أنها خلف صلاحيات صريحة لا مجرّد وجود في اللوحة.
- **العزل**: تأكيد أن `/super` (guard `system`) لا يتسرّب لـ`/admin` (guard `web`).

## خطة الدفعات المقترحة (بترتيب القيمة/المخاطرة)
1. **دفعة أمنية/عزل (P0)** — اختبارات Livewire+Pest: كل مورد يُحمَّل كأدمن بلا خطأ،
   ويُرفض للطالب؛ لا تسريب هوية/IBAN في الجداول؛ عزل الحارس. *(الأعلى قيمة، بلا مخاطر تجارية.)*
2. **دفعة مالية (P0)** — توسيع اختبارات webhook/idempotency/تسوية بحالات الحافة المفقودة.
3. **دفعة تحسين UX للوحة** — نقل/تسمية/صلاحيات منخفضة المخاطر (ADMIN_UX_RECOMMENDATIONS).
4. **منشئ صفحات الهبوط** — ميزة كبيرة (migrations + schema + Filament builder + Next renderer)؛
   تُنفَّذ كبرنامج فرعي بعد اعتماد التصميم (LANDING_PAGE_ARCHITECTURE.md).

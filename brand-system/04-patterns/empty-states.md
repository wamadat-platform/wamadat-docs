# 04.3 — Empty States

> الفَراغ فُرصَة. عَلِّم المُستَخدِم ماذا يَفعَل، لا تَتركه يَنظُر للسَماء.

## مَكتَبَة Empty States

### لم تُسَجِّل في بَرنامج
```
Icon: BookOpen
Title: لم تُسَجِّل في أيّ بَرنامج بَعد
Description: اكتَشِف بَرامِجنا المُمَيَّزَة وابدأ رِحلَتَك اليوم.
CTA: تَصَفَّح البَرامج
```

### لا نَتائج بَحث
```
Icon: Search
Title: لم نَجِد ما يُطابِق بَحثَك
Description: جَرِّب كَلِمات أُخرى أو تَصَفَّح الفِئات.
CTA: مَسح البَحث / تَصَفَّح الكَتالوج
```

### لا إشعارات
```
Icon: Bell
Title: كلّ شَيء هادِئ هنا
Description: سَنُخبِرك فَور وُصول إشعارات جَديدَة.
(لا CTA — انتِظار)
```

### لا طُلبات (Orders)
```
Icon: ShoppingBag
Title: لا طُلبات بَعد
Description: عند شراء أَوَّل بَرنامج سَيَظهَر هنا.
CTA: تَصَفَّح البَرامج
```

### لا شَهادات
```
Icon: Award
Title: شَهاداتك ستَظهَر هنا
Description: أَنهِ أَوَّل بَرنامج لِتَحصُل على شَهادَتك الأولى.
CTA: اكتَشِف البَرامج
```

### قائِمَة الأمنيات فارِغَة
```
Icon: Heart
Title: قائِمَة أمنياتك فارِغَة
Description: احفَظ البَرامج التي تَهُمُّك لِلعودَة إليها لاحِقاً.
CTA: تَصَفَّح البَرامج
```

### لا جَلسات مُباشِرَة
```
Icon: Radio
Title: لا جَلسات مُجَدوَلَة
Description: ستَظهَر هنا جَلسات البَرامج المُسَجَّل فيها.
CTA: تَصَفَّح بَرامج الدُفعات
```

### لا رَسائِل (Inbox)
```
Icon: Mail
Title: لا رَسائِل جَديدَة
Description: عند تَواصُل مع الدَعم سَتَظهَر المُحادثَة هنا.
```

---

## النَبرَة في Empty States

✅ **مُحَفِّزَة** — "اكتَشِف"، "ابدأ"، "جَرِّب"
✅ **شارِحَة** — لماذا فاضي، وماذا يَحدُث بَعد التَفاعُل
✅ **CTA واضِح** — إذا كان فيه إجراء، اعرِضه
❌ **لا تَلوم** — "أنت لم تَفعَل X" — استَخدِم "لم يَحدُث X بَعد"
❌ **لا تَترُك المُستَخدِم تائِهاً** — دائماً يُوجَد خَطوَة تالِيَة

# 04.1 — Page Layouts

> كلّ صَفحَة في ومضات تَتبَع واحِداً من 4 templates. لا تَخترِع layout جَديد.

---

## Template 1: Marketing Page (الصَفحات العامّة)

```
┌──────────────────────────────────────┐
│  Navbar (sticky)                     │
├──────────────────────────────────────┤
│                                      │
│  Hero (60-80vh)                      │
│                                      │
├──────────────────────────────────────┤
│  Value Props (3-4 cards)             │
├──────────────────────────────────────┤
│  Featured Content                    │
├──────────────────────────────────────┤
│  Social Proof / Stats                │
├──────────────────────────────────────┤
│  Final CTA                           │
├──────────────────────────────────────┤
│  Footer                              │
└──────────────────────────────────────┘
```

**استخدام:** Homepage، About، For Business، Pricing

## القَواعِد

✅ **Container يَحُدّ المحتوى** (max-width).
✅ **Mobile-first** — كلّ template يُختَزَل لـ single column على mobile.
✅ **Sticky elements مَدروسَة** (Navbar، Filter pills، Sidebar) — لا نَملأ بـ stickys.
✅ **Spacing مُتَّسِق** بَين الأقسام (`py-16 md:py-24`).
❌ **لا تَخلِط templates** في صَفحَة واحِدَة (مَثَل: Dashboard + Marketing layout).
❌ **لا full-bleed sections** غَير مُبَرَّرَة — كلّ شَيء داخل container.

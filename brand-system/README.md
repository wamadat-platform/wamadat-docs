# Wamadat Design System (WDS)

> **The constitution of the Wamadat brand.**
> دستور علامة ومضات التَجاريّة — كلّ قرار بَصريّ، لُغويّ، أو تَفاعليّ يَرجع هنا.

WDS لا يَصف "كيف تَبدو" المنصّة فقط — يَحكم **كيف تُفكِّر، كيف تَتَكَلَّم، كيف تَتَفاعَل** مع كلّ مُستخدم.

## 🎯 المبادئ الحاكمة (Operating Principles)

1. **النِظام مَصدَر الحَقيقة** — لا تُعدِّل في صَفحة، عَدِّل في النِظام. الصَفحة تَنتُج من النِظام.
2. **التَطبيق قبل النَظَريّة** — كلّ قاعِدة لها مِثال كود + أنتي-باترن مُقابِل.
3. **القَرار مَوثَّق** — كلّ "لماذا؟" مَكتوب. الذاكرة المؤسسيّة لا تَموت مع المُوظَّفين.
4. **التَغيير يَمُرّ ببَوّابة** — أيّ إضافة جَديدة → PR + Review (راجِع `08-governance/`).
5. **العَربيّة أوّلاً (Arabic-First)** — كلّ شَيء يَعمل في RTL بشَكل أصيل، لا مُترجَم.
6. **الوصول حَقّ** — WCAG 2.1 AA حَدّ أدنى، لا "إضافة لاحِقاً".

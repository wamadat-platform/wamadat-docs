# 4. مستويات خطورة المشاكل

## P0 — Blocker

يمنع الإطلاق العام، مثل:

- المنصة لا تعمل.
- فقدان بيانات.
- مستخدم يرى بيانات مستخدم آخر.
- الدفع يؤخذ دون إنشاء الطلب الصحيح.
- Enrollment لا ينشأ بعد الدفع.
- شهادة تصدر لمستخدم غير مؤهل.
- تجاوز صلاحيات جوهري.
- تكرار مالي خطير.

## P1 — Critical

خلل كبير في وظيفة أساسية، مثل:

- Checkout لا يكتمل.
- Bank Transfer لا يمكن اعتماده.
- درس أساسي لا يفتح.
- Quiz أو Assignment لا يعمل.
- Completion خاطئ.
- Certificate/Verification لا يعمل.
- لوحة دور أساسي غير قابلة للاستخدام.

## P2 — Major

خلل لا يمنع الرحلة الأساسية لكنه يؤثر بوضوح على الاستخدام.

## P3 — Minor

خلل بصري أو نصي أو تحسين غير مانع للإطلاق.

# 96. الخلاصة

يعتبر Launch V1 ناجحًا عندما تعمل الرحلة التالية بثبات:

```text
Discovery
→ Registration
→ Cart
→ Coupon
→ Checkout
→ Payment
→ Order
→ Enrollment
→ Learning
→ Quiz
→ Assignment
→ Completion
→ Certificate
→ Verification
```

وبالتوازي تعمل العمليات التشغيلية:

```text
Admin
+ Instructor
+ Attendance
+ Notifications
+ Support
+ Orders → Bank Transfer Review
+ Payments
+ Invoices
+ Coupons
+ Certificates
```

مع تحقق ثلاثة شروط غير قابلة للتنازل:

1. **لا وصول غير مصرح به.**
2. **لا ازدواجية أو خلل مالي في الرحلات الأساسية.**
3. **لا تظهر للمستخدم ميزات مؤجلة وغير مختبرة ضمن Launch V1.**

هذه القائمة هي المرجع العملي لاختبار النسخة المرشحة للإطلاق واعتمادها قبل فتح منصة ومضات للاستخدام العام.
